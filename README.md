# Adobe 작업실 — 초보자를 위한 Adobe 앱 따라 하기

Photoshop, Illustrator, Lightroom, Premiere, After Effects, InDesign, Acrobat, Adobe Express, Firefly 9개 앱을
미션·연습장·퀴즈로 하나씩 따라 하며 배우고, Adobe 커넥터로 Claude와 함께 쓰는 법까지 익히는 인터랙티브 학습 사이트입니다.

## 구성
- **시작 준비** — 계정, 설치, 메뉴 언어, 생성 크레딧
- **나에게 맞는 앱** — 만들고 싶은 것으로 앱 추천
- **앱별 실습** — 앱마다 따라 하기 미션 5개, 연습장(시뮬레이터) 1개, 단축키, 새 기능, Claude 요청 예시, 퀴즈 3개
- **Claude와 함께** — 커넥터 연결 순서, 할 수 있는 일, 요청 모음
- **실전 레시피** — 썸네일, 릴스, 포스터, 로고, 자료집, 모션 인트로
- **미니 게임** — 단축키 챌린지, 이 작업엔 어떤 앱?
- **용어 사전 · 수료증** — 800 XP 이상이면 수료증 인쇄

진도(XP)는 브라우저 localStorage에 저장됩니다.

## 파일
```
index.html
css/style.css
js/data.js   콘텐츠(앱·미션·퀴즈·용어 등)
js/sims.js   연습장 시뮬레이터 9종
js/app.js    라우터·진도·페이지 렌더링
```

Adobe 및 각 앱 이름은 Adobe Inc.의 상표이며, 이 사이트는 비공식 학습 자료입니다.
